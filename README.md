# OFFLIMIT E-commerce Store

Premium streetwear storefront built for the OFFLIMIT brand.

## Included
- Responsive homepage
- OFFLIMIT wordmark + symbol assets extracted from supplied brand reference
- Product catalog and category filters
- Product quick-view modal
- LocalStorage cart
- Newsletter form UI
- Mobile-responsive layout
- Checkout integration-ready button
- About/story and social sections

## Product images
The included product images are temporary branded mockups. Replace them in `assets/` with the final product photography without changing the product card code.

## Launch
Upload the contents of this folder to GitHub and connect the repository to Vercel.

## Production e-commerce
The front end is ready for integration with a payment/order backend. Connect Stripe, Shopify Storefront API, WooCommerce, or another commerce backend before taking live payments.
